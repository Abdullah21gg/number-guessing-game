# number-guessing-game
a simple number python guessing game
# Features
random number generation: (1,10)
the game gives hints (too high or too low) till the number is guessed correctly
handles invalid input without crashing
# tech stack
was built using python 3
# how to run it
[git clone https://github.com/Abdullah21gg/number-guessing-game/tree/main
then
python game.py
inside of the terminal
# what i learned
using while and for loops to ask for input and print output
using try/except to handle invalid input
working with random module
